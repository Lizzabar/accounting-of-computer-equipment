# accounting-of-computer-equipment
Разработка программы учёта компьютерной техники в организации
**Тема работы** — Разработка программы учёта компьютерной техники в организации.

**Основание для разработки** — потребность организаций в автоматизации процессов учёта компьютерной техники, повышении оперативности получения сведений о состоянии оборудования, обеспечении контроля гарантийных сроков и сроков технического обслуживания, а также в снижении трудозатрат на проведение инвентаризации.

**Категории пользователей:**
Роль	Права доступа
Администратор	Полный доступ: управление пользователями, настройка системы, работа со справочниками, резервное копирование
Специалист по учёту техники	Добавление, редактирование и удаление записей о технике, ведение истории обслуживания, формирование отчётов
Руководитель ИТ-отдела	Просмотр всех записей, анализ отчётов, контроль гарантийных сроков и сроков обслуживания
Технический специалист	Просмотр закреплённой техники, внесение отметок о ремонте и обслуживании
Сотрудник	Просмотр общедоступных сведений о закреплённой за ним технике

**Функциональные требования к системе:**
1. Ведение справочников: типы техники, модели, производители, подразделения, сотрудники, статусы техники.
2. Регистрация единицы техники с автоматическим присвоением инвентарного номера.
3. Прикрепление электронных документов (накладные, гарантийные талоны, акты).
4. Учёт перемещений техники между подразделениями и ответственными лицами.
5. Ведение истории ремонтов и технического обслуживания.
6. Контроль гарантийных сроков с формированием уведомлений.
7. Формирование отчётов: реестр техники, отчёт по подразделению, отчёт по затратам на обслуживание, отчёт о технике с истекающим гарантийным сроком.
8. Поиск техники по различным реквизитам.
9. Списание устаревшей техники с формированием акта.
10. Разграничение прав доступа на основе ролевой модели.
